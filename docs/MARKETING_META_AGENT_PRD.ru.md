# PRD: Автономная Мета-Агентная Система (Marketing Domain)

## 1. Концепция
Создание системы "высшего порядка", где агенты не просто выполняют задачи, а могут расширять собственные возможности и возможности системы для достижения бизнес-целей (на примере Маркетинга). Агент переходит из статуса "Исполнитель" в статус "Менеджер/Технолог".

## 2. Ключевые Возможности (Meta-Capabilities)

### 2.1. Создание Навыков (Self-Tooling)
*   **Проблема**: Для новой маркетинговой платформы (например, TikTok) нет инструментов.
*   **Решение**: Система анализирует API документацию платформы и пишет новый код инструмента (Skill) в `packages/solopreneur`.
*   **Сценарий**:
    1. Пользователь: "Начни постить в Threads".
    2. Агент: "У меня нет инструмента Threads".
    3. Агент: Ищет API -> Генерирует `ThreadsPostTool` -> Тестирует -> Сохраняет.

### 2.2. Создание Агентов и Субагентов (Agent Spawning)
*   **Проблема**: Универсальный агент "Маркетолог" плохо пишет узкоспециализированные тексты.
*   **Решение**: Мета-агент создает специализированных субагентов.
*   **Сценарий**:
    *   Создать "Копирайтера для Твиттера" (ограничение 280 символов, дерзкий тон).
    *   Создать "SEO-специалиста" (фокус на ключевики, сухой тон).
    *   Агент генерирует конфиг в `opencode.json` (или динамический) и промпт.

### 2.3. Создание Воркфлоу (Workflow Generation)
*   **Проблема**: Повторяющиеся ручные действия (написать пост -> сделать картинку -> запостить).
*   **Решение**: Агент наблюдает за последовательностью действий или получает инструкцию и "цементирует" её в файл `.agent/workflows/blog-post.md`.
*   **Функционал**: Генерация YAML/Markdown файлов воркфлоу, которые потом можно запускать одной командой.

### 2.4. Оркестрация (Orchestration)
*   **Функция**: Способность разбивать высокоуровневую задачу ("Запусти кампанию на месяц") на подзадачи и делегировать их созданным субагентам.
*   **Механизм**: Главный агент (Chief Marketing Officer) держит контекст стратегии и раздает таски исполнителям (Writer, Designer, Poster).

### 2.5. Обратная Связь и Самоулучшение (RLHF Loop)
*   **Механизм**:
    *   Сбор метрик (лайки, ретвиты, ошибки компиляции).
    *   Анализ результата ("Почему пост не взлетел?").
    *   **Self-Correction**: Обновление промпта субагента или кода навыка на основе неудачи.

## 3. Архитектура Реализации (в `packages/solopreneur`)

### Новые Инструменты (Meta-Tools)
Эти инструменты будут доступны "Главному Агенту":
1.  `expert_creator`: Создание промпта и конфигурации нового агента.
2.  `skill_scaffold`: Генерация шаблона TypeScript кода для нового навыка.
3.  `workflow_writer`: Запись последовательности шагов в `.agent/workflows`.
4.  `feedback_analyzer`: Чтение метрик и модификация файлов конфигурации.

### Специальные Агенты (Roles)
1.  **Architect (Meta-Agent)**: Единственный агент, имеющий доступ к `expert_creator`, `skill_scaffold` и `write_file` (в кодовой базе).
2.  **CMO (Chief Marketing Officer)**: Пользуется ресурсами, но не может менять код системы.
3.  **Executors (Writer, Poster)**: Имеют доступ только к инструментам выполнения (post_tweet, write_article).

## 4. Безопасность и Разграничение Прав
Чтобы избежать хаоса, мы строго разграничиваем доступы:
*   Обычные агенты **НЕ** видят инструменты создания кода/агентов.
*   Только **Architect** может коммитить изменения в `packages/solopreneur`.
*   Человек должен подтверждать (approve) любые изменения в конфигурации агентов (`opencode.json`).

## 6. Визуальный Дашборд (Control Panel)
Вместо работы с "портянками" текста, реализуется веб-интерфейс (или расширение существующего):
*   **Agent Grid**: Отображение активных агентов, их статусов и текущих задач.
*   **Workflow Visualizer**: Графическое представление цепочек действий (steps).
*   **Metrics**: Графики эффективности (например, просмотры постов).
*   **Approval Center**: Интерфейс для подтверждения действий (Approve/Reject), которые требуют вмешательства человека (создание новых агентов, публикация).

## 7. План Разработки (MVP - Marketing)
1.  **Agent Creator (Tool)**: Реализовать инструмент для `Architect`.
2.  **Dashboard MVP**: Простая страница (React/Solid), отображающая список агентов из `opencode.json`.
3.  **Skill Generator**: Инструмент генерации навыков.
4.  **Feedback Loop**: Механика метрик.
